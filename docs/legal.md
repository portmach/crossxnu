# Лицензии и границы распространения

## 1. Лицензии компонентов

| Компонент | Лицензия | Что можно распространять |
|:----------|:---------|:-------------------------|
| XNU | APSL-2.0 | исходники и производные патчи |
| bootstrap_cmds (MIG) | APSL-2.0 | исходники и производные |
| AvailabilityVersions | APSL-2.0 | исходники |
| libdispatch | Apache-2.0 | исходники и производные |
| iig-port | MIT | исходники и производные |
| cctools-port | APSL-2.0 (Apple cctools), порт — см. upstream | исходники и производные |
| libclang (clang) | Apache-2.0 with LLVM exceptions | host-зависимость, не вендорится |
| Оригинальные скрипты/документы crossxnu | MIT | да |

Патчи crossxnu — производные от XNU и распространяются под APSL-2.0.
Файл `LICENSE` в корне — MIT для оригинальных файлов; для патчей и
кода, скопированного из XNU, действует APSL-2.0 (указание в заголовке
файла/патча).

## 2. Чего в репозитории нет и не будет

- Apple SDK (`MacOSX*.sdk`), KDK, Xcode;
- собранных ядер Apple, kext'ов, dyld shared cache;
- проприетарных драйверов (`AppleACPIPlatform`, `AppleAPFS`, GPU и т.п.);
- бинарников, извлечённых из macOS.

Synthetic SDK генерируется из открытых исходников; он не содержит
Apple-бинарников. Если пользователь подключает собственный SDK, он
хранится **вне** репозитория и не коммитится.

## 3. Товарные знаки

XNU, Darwin, macOS, IOKit, DriverKit — товарные знаки Apple Inc.
Проект не affiliated with Apple; использование названий —
номинативное, для описания совместимости.

## 4. Ответственность

Проект не обходит код-сигнатуры, DRM и лицензионные ограничения macOS.
Загрузка ядра на реальном железе Apple может нарушать условия
лицензии macOS; ответственность за это несёт пользователь. QEMU и
собственное железо — безопасная песочница для разработки.
